WHY THE LINKS ARE PLAIN WEB LINKS --------------------------------- The signed-in grid links each card through `app_first_href('product', id)`, which is an interstitial that tries the app first. That is right for a member on a phone and wrong for this page in one specific way: an interstitial is not the product's canonical URL, so a crawler following forty of them learns about forty redirects instead of forty products, and the internal link that should strengthen a product page instead points somewhere that cannot be indexed. So the card title links to `/pulse/marketplace/` -- the canonical URL, the same string the sitemap and the feed will carry -- and the app is promoted once, in the header CTA and the footer badge, where it is an offer rather than a toll on every link. WHAT IS DELIBERATELY ABSENT --------------------------- Contact Seller, Save, Report and Promote are each a POST that needs a session, and the seller forms (Apply as Merchant, Create Listing) need an account before they mean anything. None are rendered as dead buttons; the sign-in link states the requirement before the click. The live search box is absent for the same reason in a different form: `/api/pulse/marketplace/search` requires a session, so a search field here would be a text input that fails on submit.
