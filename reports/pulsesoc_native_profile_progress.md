# PulseSoc Native Profile V2 Progress

Date: 2026-07-15

## Outcome

Profile V2 now uses the existing production identity, posts, follow graph, Messenger, media, Premium entitlement, and profile-theme storage. No native-only identity, follower graph, conversation, upload, cache authority, or user database was introduced.

The design was informed by the supplied Profile, Customize Profile, theme gallery, layout gallery, statistics, media, About, and music mockups. They were treated as hierarchy and atmosphere references; the rendered app continues to use real PulseSoc account data and current native design tokens.

## Canonical contracts

- `GET /api/pulse/profile/me` now returns the canonical identity plus real post, media, follower, and following counts.
- `GET /api/pulse/profile/<profile_key>` is a read adapter over the existing `users`, identity engine, follow graph, post table, and profile-theme table. It replaces the old native behavior that inferred a public profile from the first feed post.
- `GET/POST /api/pulse/premium/profile-theme` remains the existing Profile customization authority. Native reads are allowed; writes still require the existing Premium entitlement.
- `POST /api/pulse/follows/toggle` remains the Follow/Unfollow authority.
- `POST /api/pulse/messages/direct/open` remains the canonical direct-conversation open/create authority.
- Existing profile update, avatar, cover, remove, feed-filter, privacy, verification, badge, moderation, and media rules remain authoritative.

## Profile V2 implementation

- Living identity header with real cover/avatar/name/handle/bio/badges/stats.
- Subtle atmosphere, orbit, avatar aura, and signal motion using native animation primitives.
- System Reduce Motion and the saved reduced motion setting stop ambient animation.
- Smart owner actions: Edit Profile, Customize, Share, Growth, Safety, Refresh.
- Smart public actions: Message, Follow/Following, Share, Safety, Refresh.
- Message opens or creates the existing canonical Messenger direct thread and navigates into it.
- Follow state and follower count reconcile from the server result.
- Identity, Media, Music, and Trust modules provide the Profile hierarchy without fake analytics.
- Existing Posts, Media, and About tabs remain backed by the production feed/profile contracts.
- Offline reads use the existing per-profile AsyncStorage cache; server data remains authoritative.

## Server-backed customization

The existing `pulse_profile_themes` table is extended additively with `layout_key`, `modules_json`, and `motion_level`. Release/payment behavior is unchanged.

Themes: Deep Space, Neon Galaxy, Cyber City, Solar Pulse, Aurora, Quantum, Crystal, Dark Matter, Nova, Minimal Black.

Layouts: Classic, Creator, Professional, Minimal, Artist, Music, Gaming, Developer, Business, Streamer.

Motion: Subtle, Balanced, Reduced.
