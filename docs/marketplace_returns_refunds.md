# Marketplace Returns and Refunds

Eligible physical goods default to a 14-day return-request window after delivery. Policy types are returns accepted, final sale, defect only, and category policy. Personalized, perishable, opened hygiene-sensitive, digital, and legally restricted goods may be excluded by versioned category rules.

Seller-fault returns include wrong, damaged, counterfeit, or materially misdescribed items; buyer-remorse return shipping is buyer-paid unless the seller offers free returns. Refunds are server-authoritative and reconcile buyer funds, tax, shipping, seller ledger, platform-fee reversal, processor state, and order state exactly once.
